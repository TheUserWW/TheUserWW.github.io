# Codeforces 1195C - Basketball Exercise

[Codeforces - 1195C](https://codeforces.com/contest/1195/problem/C)

## Problem Idea

This is a dynamic programming problem. We need to choose students from two rows such that:

1. We choose students from left to right (by index).
2. Each chosen student must have a strictly greater index than the previous one.
3. No two consecutive chosen students can be from the same row.
4. We maximize the total height of all chosen students.

This is a classic restricted selection problem where the state must track both position and the last choice.

---

## Key Observation

The crucial observation is that we need to track:

- The current position `i` in the problem
- Which row the last chosen student came from (row A or row B)

This allows us to enforce the constraint that consecutive students must come from different rows.

We can define a DP state as `dp[i][j]` where:
- `i` is the current position (1 to n)
- `j` indicates the action at position `i`:
  - `j = 0`: pick a student from row A
  - `j = 1`: pick a student from row B

The value `dp[i][j]` represents the maximum total height when we are at position `i` and take action `j`.

---

## Why Not Use a Naive Approach?

A naive approach might be to use a 3-state DP with an explicit "skip" state:

```
dp[i][0] = pick from row A
dp[i][1] = pick from row B
dp[i][2] = skip this position
```

This would work, but we can optimize it. The key insight is that skipping is dominated by previous good states, so we don't need an explicit skip state.

Instead, we can reduce to a 2-state DP by recognizing that:

$$
C_{k-1} \le B_k \quad \text{and} \quad C_{k-1} \le A_k
$$

where `C_k` represents the value of skipping. Thus, the skip state is always subsumed by one of the pick states from the same or previous position.

---

## State Transitions

### Base Case: `i = 0`

No students have been considered yet:

```cpp
dp[0][0] = 0
dp[0][1] = 0
```

### Base Case: `i = 1`

For the first position, we can either pick from row A or row B:

```cpp
dp[1][0] = rowA[0]
dp[1][1] = rowB[0]
```

### General Case: `i ≥ 2`

For `dp[i][0]` (pick from row A at position `i`):

Since we cannot pick from row A consecutively, the previous chosen student must come from row B or earlier. The valid transitions are:

$$
dp[i][0] = \max(dp[i-1][1], dp[i-2][0], dp[i-2][1]) + rowA[i-1]
$$

For `dp[i][1]` (pick from row B at position `i`):

Similarly, the previous chosen student must come from row A or earlier:

$$
dp[i][1] = \max(dp[i-1][0], dp[i-2][1], dp[i-2][0]) + rowB[i-1]
$$

The final answer is:

$$
\max(dp[n][0], dp[n][1])
$$

---

## Correctness

The DP is correct because:

1. Each state represents an optimal choice up to position `i` with a specific last row.
2. The transitions only consider valid previous states (from different rows).
3. By always picking the maximum from valid predecessors, we ensure optimality.
4. The recurrence relation covers all cases and correctly enforces the "no consecutive same row" constraint.

---

## Complexity

- Time: `O(n)` — we compute each DP state once.
- Space: `O(n)` — we store `2n` values (can be optimized to `O(1)` with rolling arrays).

---

## C++ Implementation

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    vector<ll> rowA(n), rowB(n);

    for (int i = 0; i < n; i++) {
        cin >> rowA[i];
    }
    for (int i = 0; i < n; i++) {
        cin >> rowB[i];
    }

    if (n == 1) {
        cout << max(rowA[0], rowB[0]) << '\n';
        return 0;
    }

    vector<vector<ll>> dp(n + 1, vector<ll>(2, 0));

    dp[1][0] = rowA[0];
    dp[1][1] = rowB[0];

    for (int i = 2; i <= n; i++) {
        dp[i][0] = max({dp[i - 1][1], dp[i - 2][0], dp[i - 2][1]}) + rowA[i - 1];
        dp[i][1] = max({dp[i - 1][0], dp[i - 2][1], dp[i - 2][0]}) + rowB[i - 1];
    }

    cout << max(dp[n][0], dp[n][1]) << '\n';

    return 0;
}
```

---

## Space Optimization with Rolling Array

Since we only need values from `i-1` and `i-2`, we can optimize space to `O(1)` using a rolling array:

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    vector<ll> rowA(n), rowB(n);

    for (int i = 0; i < n; i++) {
        cin >> rowA[i];
    }
    for (int i = 0; i < n; i++) {
        cin >> rowB[i];
    }

    if (n == 1) {
        cout << max(rowA[0], rowB[0]) << '\n';
        return 0;
    }

    vector<vector<ll>> dp(2, vector<ll>(2, 0));

    dp[1 % 2][0] = rowA[0];
    dp[1 % 2][1] = rowB[0];

    for (int i = 2; i <= n; i++) {
        ll cur_0 = max({dp[(i - 1) % 2][1], dp[i % 2][0], dp[i % 2][1]}) + rowA[i - 1];
        ll cur_1 = max({dp[(i - 1) % 2][0], dp[i % 2][1], dp[i % 2][0]}) + rowB[i - 1];
        dp[i % 2][0] = cur_0;
        dp[i % 2][1] = cur_1;
    }

    cout << max({dp[0][0], dp[0][1], dp[1][0], dp[1][1]}) << '\n';

    return 0;
}
```

This optimized version uses only `O(1)` space while maintaining the same time complexity.

---

## Final Summary

The problem reduces to a 2D DP where:

- `dp[i][0]` = maximum height when picking from row A at position `i`
- `dp[i][1]` = maximum height when picking from row B at position `i`

The key constraint is that consecutive choices must alternate between rows, which is naturally enforced by the transitions. We can further optimize space using rolling arrays if needed.
